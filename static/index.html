      Architecture Decisions reconstructed from history
      
      
      Decision points are detected deterministically (dependencies adopted or replaced, infrastructure and module groups introduced, violations introduced or resolved). Nearby commits are ranked by relevance = 0.3·time + 0.45·graph + 0.25·text, and the AI writes each record only from that evidence, including the text of the GitHub pull requests and issues those commits belong to, which is where developers usually explain why. A reason is reported as stated only when that text states it; otherwise it is marked as inferred.
