# RepoMind AI Documentation

This directory contains technical specifications, architecture blueprints, and testing guides for RepoMind AI:

- **[Testing Strategy (`TESTING.md`)](TESTING.md)**: Detailed test suite documentation, fixture guidelines, offline verification boundaries, and execution instructions across the 211 automated test cases.
- **[Architecture Diagram Output (`diagram_output.md`)](diagram_output.md)**: Exported Mermaid graph diagrams illustrating module dependencies, layers, and historical evolution intervals.
